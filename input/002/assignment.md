# JSON-andmete kuvamine

## Ülesande kirjeldus
Loo veebileht, mis laeb JSON-failist andmed ja kuvab need tabelina kasutajale. Andmed sisaldavad isikute nimesid ja vanuseid.

## Nõuded
- JSON-fail peab olema eraldi fail ja sisaldama vähemalt 5 objekti
- Andmete laadimine peab toimuma JavaScripti fetch() abil
- Veebileht peab kuvama veateate, kui andmete laadimine ebaõnnestub
- Tabel peab olema CSS-ga vormindatud
- Kasutaja saab andmeid otsida nime järgi

## Hindamiskriteeriumid
- [ ] JSON-fail on korrektses vormingus ja eraldi failis
- [ ] fetch() töötab ja andmed kuvatakse
- [ ] Otsingufunktsionaalsus filtreerib tabeli ridu
- [ ] Veateated on kasutajale nähtavad
- [ ] Leht on responsive
