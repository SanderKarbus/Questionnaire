# Tehisintellekti vestlusrobot

## Ülesande kirjeldus
Loo lihtne Pythoni vestlusrobot, mis kasutab tekstifaili teadmistebaasina. Robot vastab kasutaja küsimustele, leides sobivaima vastuse failist.

## Nõuded
- Programm peab lugema teadmistebaasi tekstifailist
- Kasutaja saab sisestada küsimuse ja saab vastuse
- Kui vastust ei leita, peab programm ütlema "Kahjuks ei oska sellele vastata"
- Programm töötab käsurealt (CLI)
- Toetada vähemalt 5 erinevat teemat

## Hindamiskriteeriumid
- [ ] Teadmistebaasi fail on eraldi ja loetav
- [ ] Otsing töötab ja leiab õige vastuse
- [ ] Tundmatu küsimuse korral kuvatakse vaikevastus
- [ ] Programm ei jää kinni lõputusse tsüklisse
- [ ] Kood on loetav ja kommenteeritud
