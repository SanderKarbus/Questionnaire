# JavaScripti kalkulaator

## Ülesande kirjeldus
Loo lihtne veebikalkulaator, mis võimaldab kasutajal teha põhilisi aritmeetilisi tehteid (liitmine, lahutamine, korrutamine, jagamine).

## Nõuded
- Kasutajaliides peab sisaldama kahte sisendvälja ja tehtevaliku nuppe
- Arvutustulemus peab kuvatakse lehel pärast nupuvajutust
- Vigase sisendi korral peab kuvatakse veateade
- JavaScript peab kasutama sündmuste kuulamist (addEventListener)
- Väljund peab olema vormindatud kahe komakohaga

## Hindamiskriteeriumid
- [ ] HTML struktuur on semantiline ja valideeruv
- [ ] CSS on eraldi failis ja leht on kasutajasõbralik
- [ ] JavaScript töötab ilma vigadeta
- [ ] Kõik neli tehet töötavad
- [ ] Veakäsitlus on olemas (nt tühja sisendi või tekstiga)
